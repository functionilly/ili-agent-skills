# Specify the target form in prose, and put bans in checks

**Scope:** repo-wide — all skill prose and seed files
**Rule:** Instruction prose states the exact target form, with one worked example of the artifact to write. Lists of forbidden patterns live only inside mechanical checks, such as the history check (check-decision-docs-for-history).
**Why:** Agents copy the form they see; a prohibition gives no form to copy, and a prohibition list grows without bound. A check enforces a ban better than prose does. The cost: a worked example takes more tokens than a ban. We accept that cost.
