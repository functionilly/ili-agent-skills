# Write all skills in Simplified Technical English

Skill files are instructions that an agent must parse the same way in every session.
We adopted ASD-STE100 (Issue 9) as the writing standard for all prose in this repo.
STE gives short sentences, active voice, one meaning per word, and one instruction per sentence.
This reduces ambiguity for the agent and reduces token use. The trade-off: some nuance from
the upstream texts is compressed. We accept that trade-off. See `docs/STE-GUIDE.md`.
