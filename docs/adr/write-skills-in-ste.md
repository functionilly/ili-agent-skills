# Write all skills in Simplified Technical English

**Scope:** repo-wide — all prose in skills, docs, and seed files
**Rule:** Write all prose to ASD-STE100 (Issue 9), in the pragmatic form of `docs/STE-GUIDE.md`.
**Why:** Agents must parse instructions the same way in every session. STE gives short sentences, active voice, and one meaning per word. This cuts ambiguity and token use. The cost: some nuance from the upstream texts is compressed. We accept that cost.
