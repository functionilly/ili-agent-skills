# Triage labels

The skills speak in five canonical triage roles. This file maps each role to the label
string in this repo's issue tracker. Edit the right column to match your vocabulary.

| Canonical role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate this issue. |
| `needs-info` | `needs-info` | The issue waits on the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified. An AFK agent can take it. |
| `ready-for-human` | `ready-for-human` | Needs human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill names a role, apply the label string from this table.
